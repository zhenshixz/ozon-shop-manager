# OZON 店铺助手

**微信接收上新和出单，填采购价核算利润，用数据罗盘查看店铺与商品表现。**

面向OZON多店铺卖家，从10家店铺、两人共同管理的需求出发，整合推送、核算和经营分析。适配手机与电脑，无需安装专用App。

## 产品亮点

### 多店铺微信推送

- 统一采集多店铺上新、出单，覆盖FBS/rFBS与FBO订单。
- 通过Pushplus群组共同接收，订单通知可带商品名、图片、售价、数量及利润页入口。
- 订单汇总、上新日报分别调度，记录发送状态，正常重启不重复提醒。到达时间取决于配置、API及微信投递。

### 自动核算订单利润

同步商品、售价、数量与重量，填写实际采购单价后查看预估利润。

```text
预估利润 = 核算售价 − 采购成本 − 运费 − 平台合计扣费 − 货代费 − 其他成本
```

- 按人民币售价和有效计费重量自动匹配四档费用，无需逐单选公式。
- 支持确认后使用实际称重，调整费用时可预览试算并查看明细。
- 资料不完整时保持待补状态，不将未填采购成本当作零。利润为预估，具体规则见[项目说明](docs/PROJECT.md)。

### 采购成本可追溯

- 按“已填采购单价 × 数量”统计，支持日期筛选。
- 取消/退货订单的已填成本单独列明。
- 明细展示图片、店铺、订单、商品、采购成本、售价和利润，可继续进入核算。

### 数据罗盘：从店铺看到商品

首页集中显示成本、销售额、利润、利润率及近7日均单量；详细分析放在罗盘中。

| 功能 | 重点 |
| --- | --- |
| 商品 / 店铺双维度 | 全局比较，也能只看某一家店 |
| 销量榜、利润榜、亏损榜 | 商品利润可切单件/累计，店铺按累计利润排名 |
| 经营趋势与筛选 | 查看订单量、销售额、利润，支持快捷日期和自定义区间 |
| 逐层查看 | 店铺榜 → 店内商品 → 商品详情 → 关联订单，返回保留筛选与位置 |

商品标题支持中文/原文切换，图片可放大；缺图持续重试并复用缓存，翻译由本地模型服务提供。

## 统计口径

- 销售额包含未填成本的有效订单；利润与利润率只统计同批完整核算的有效订单。
- 取消/退货不计入利润合计；商品单件利润只除以已核算件数。
- 订单列表最多显示最近500个包裹，罗盘按筛选范围全量聚合。

## 使用流程

接入店铺与Pushplus → 微信收到订单 → 填采购价、核对并保存 → 罗盘查看经营表现。
