# OZON店铺助手 · 妙手同步MVP（Chrome / Edge）

版本0.1.0。仅读取妙手当前页的必要字段，每批1—5笔，在线核对后确认更新。不会自动翻页，不操作妙手的采购/发货按钮，不读取Cookie，不要求填写OZON Key。

## 安装

1. 下载ZIP后解压，保留文件夹。
2. Chrome打开 `chrome://extensions/`；Edge打开 `edge://extensions/`。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中包含manifest.json的 `ozon-miaoshou-sync` 文件夹。
4. 将扩展固定到浏览器工具栏，方便使用。两款浏览器使用同一份文件。

## 第一次测试

1. 在已登录妙手的订单列表里打开几笔属于自己的OZON订单。先选择单款商品订单（同款多件可以），确保页面能看到店铺、完整订单号、平台SKU、SKU ID、数量、采购金额和本地备注。
2. 点击插件→读取当前页→勾选1—5笔→前往线上核对。
3. 在线页面逐项显示当前值和新值，默认“增量更新”。有冲突的字段默认不选；先核对订单、件数及金额，再勾选并确认保存。页面保存会真正更新线上对应订单。
4. 可从本浏览器更新记录撤销该批；订单已再次修改时不能直接撤销，需要到详情核实。

## 数据含义

- 采购金额必须是人民币商品行合计，系统按件数除成单件价，保留精度。
- 明确写成 `312g` / `854克` 的备注按本单整包重量保存，不再乘件数。
- 空采购/0元采购保留旧值，记录待补价；日期备注如 `11-11:2-2` 不猜成重量。
- 没采购价的订单不会标为同步完成。以后重新读取到这笔订单时，即使是旧订单，补上的采购价也会重新核对。未重新读取到的仍留在“待补与待核对”，可复制待补价单号到妙手搜索后重新读取。
- MVP当前没有后台全天自动补查或跨页搜索。只读取已打开页面，不把未查到的旧单标成“已核对”。
- 重复同步相同值跳过；妙手未变而系统后来手动改过则保留系统值。选择“全量核对本批”会重新比较本批5笔内的数据，冲突仍需勾选，空值不清空，未读取订单不变。
- 混款、多种SKU、已有拆包方案的重量、件数不符等会提示核实。不会修改本批之外的同款订单。

## 读取失败

插件会显示缺少或不唯一的字段，不能识别时不会猜测后保存。检查是否在 `*.91miaoshou.com` 的订单列表、字段是否完整显示。妙手页面结构仍需在你的真实登录页面用小样适配确认；截图只能辅助判断，不能替代真实读取验证。

仅保存必要字段到浏览器会话内存，传给自己的店铺助手核对页；浏览器关闭后传递缓存清除。扩展没有第三方服务、广告、统计或远程代码。
