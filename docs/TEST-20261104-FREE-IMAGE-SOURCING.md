## 结果

### 1. 1688原生免费网页

在1688首页选择本地图片，预览正确；点击图片搜索后，新标签页跳转1688/淘宝登录流程。该匿名环境没有取得网页商品结果。

结论：原生网页确有免费交互入口，但“直接拼一个链接就能匿名稳定得到结果”未跑通。

### 2. 1688官方采购助手：成功取得真实搜索结果

从[官方发布网站](https://chajian.1688.com/)下载官方离线包，在独立测试浏览器加载，版本1.2.2。官方页面明确标注“完全免费”。使用浏览器插件正常的上传图片和搜索功能，没有调用私有接口来仿造服务，也没有修改插件。

- 扭力适配器：出现相关仪表商品，首屏有89.00元、96.80元、130元等参考报价，同时显示店名和起批量；仅确认外观和类目相近，未确认量程、附件和最终成交规格一致。
- 种植袋：结果随图片改变，出现七格/多格种植袋；其中有9.90元等报价。也混有2.30元、3.88元等其他规格/产品的摘要报价，不能直接当作90cm七格产品的实际采购价。
- 点击一件多格种植桶商品卡，打开了对应1688商品目标；可识别目标商品ID为1060717090125。详情在匿名状态又要求登录，所以未核验该商品的完整SKU/运费或下单价。
- 本地商品样例列表中，悬停图片可出现“1688帮你找”入口，点击可打开插件内结果面板，证明无需部署服务器接口即可从普通网页触发检索。
- 组合图存在主体识别误差：本地列表测试时，扭力适配器的附送接头被当作主体，返回0.98元等接头报价。需人工框选主体；本轮未完成框选后复核，不宣称已解决此误差。

结论：1688插件的免费搜索已实际取得结果。匹配质量需要人工确认；匿名可见搜索摘要不代表所有功能和详情免登录，更不代表无限次、永久开放API。

### 3. 同一官方插件切换淘宝：停在登录条件

切换“淘宝”后出现“请先登录1688后再查看商品信息”“立即登录”，未得到可验证的淘宝商品列表。旁边仍出现的1688源头货源推荐不能计作淘宝搜索成功。

结论：淘宝渠道存在，但本轮没有完成正常登录后的搜索验证，不能计为已跑通。登录是账号条件，不等于收费；本轮没有可用账号，未代注册或绕过验证。

### 4. AiPrice免费替代路径：未通过

官网[批量图搜](https://www.aiprice.com/img/search)接受图片上传。进一步在另一个独立浏览器安装其官网提供的免费插件（4.2.2），再次上传和提交后，页面跳转AiPrice登录并显示安全验证；未获取可验证的淘宝结果。

结论：不能把宣传“免费图搜”写成匿名服务器可调用的免费长期接口；本轮不把该路径列为已验收方案。

### 5. 官方/第三方API路线

实看遨虾API页可见积分套餐；没有找到并开通适用于我们项目、已验证长期免费的图搜凭证。套餐页包含多种服务，不能仅凭套餐价格断言每个具体接口必定收费。

淘宝联盟接口虽然文档标免费，但仍需开发者应用、推广位/权限等条件，本轮没有相应可用凭证。没有伪造AppKey、广告设备标识，或使用他人泄漏的Key。此前调研的第三方试用不符合“免费长期”要求，未购买或申请作为正式方案。

## 能交付与不能交付的边界

当前可以复现的免费工作流：浏览器安装1688官方采购助手 → 打开商品图片/在图片上触发搜图 → 人工确认主体、规格及供应商 → 打开真实商品核价。需要登录时在平台官方页面由账号本人完成；详情和淘宝仍需实际登录验证。

此工作流依赖官方面向用户的界面，免去我们维护抓取、账号池和付费API的成本，是目前最可维护的免费候选。尚不能称为“1688和淘宝均已验收、无人干预长期稳定运行”。

目前没有找到并实测通过以下全部条件的方案：不装插件、无需任何账号/应用准入、在我们网页内自动返回两平台同规格商品和实时到手价、长期免费且稳定。不得把试用、仅打开登录页、混用1688推荐、调用插件私有接口当作成功。

在上线前，淘宝登录后结果及账号跨日保持、列表入口在实际页面的交互仍需要验证；本轮遵守用户指令，不修改线上页面。
