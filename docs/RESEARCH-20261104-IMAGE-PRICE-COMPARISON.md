# 订单列表以图搜货及比价调研

调研日期：2026-11-04。范围：1688、淘宝、拼多多；只调研，没有开发功能、修改服务器、注册/购买服务或调用付费接口。

## 结论

可分阶段做“图片寻找候选货源 + 参考价对比”。不能承诺三平台同时稳定覆盖、自动识别所有同规格商品、返回用户真实到手最低价。

优先验证1688官方渠道，再验证淘宝官方权限或第三方；拼多多暂不作为自动聚合比价的验收范围。接口存在、能获取权限、搜索质量合格是三个独立条件，目前只完成公开文档调查。

## 一手资料及已确认事实

### 1688

- [官方 AlphaShop / 遨虾 MCP 服务](https://www.alphashop.cn/seller-center/home/mcp-list)展示多语言图搜，可以返回价格、销量和商家信息；同时有商品详情能力。公开页面能证明服务存在，不能证明当前账号可立即开通。
- [官方跨境综合解决方案协议](https://terms.alicdn.com/legal-agreement/terms/b_end_product_protocol/20231024161027594/20231024161027594.html)服务内容1.3明确提供货盘中的文字和多图、多链接图片搜索；相关接入有资质、开放平台及方案要求。该完整方案与遨虾各具体产品的准入不能混为一谈。服务内容第2条说明不保证图搜及比价准确性。
- [官方采购助手Chrome商店页](https://chromewebstore.google.com/detail/1688%E5%AE%98%E6%96%B9%E9%87%87%E8%B4%AD%E5%8A%A9%E6%89%8B/kphldkppgfpjadpabfkghmjbhpcmgpdg?hl=zh-CN)开发者网站为chajian.1688.com，支持任意网页截图/链接/文本找同款；跨平台比价结果明确列1688、淘宝、Amazon、AliExpress、Alibaba。拼多多出现在其他覆盖平台描述中，不能据此证明能返回拼多多采购结果。
- 未核实：当前账号权限、具体图搜单价/QPS、可用货盘覆盖、任意OZON外链图片的上传要求。须拿实际商品图验证。

### 淘宝

- [识图找优惠商品List，apiId=73442](https://developer.alibaba.com/docs/api.htm?apiId=73442)，真实官方接口名 `taobao.tbk.dg.image.ecognition.list.query`。图像Base64小于200K，支持jpg/png；返回标题、图片、售价、到手价及推广跳转链接。文档标免费、不需要用户授权，但仍需应用AppKey、签名、推广位；必填用户标识类型只列IDFA_MD5/OAID_MD5，不能假设普通桌面网页可以自然取得，也不能随意伪造。
- [淘宝联盟厂商找优惠，apiId=55438](https://developer.alibaba.com/docs/api.htm?apiId=55438)，接口名 `taobao.tbk.thor.mfrs.promotion.query`。支持图片或淘口令识别淘内相似商品，对符合条件的商品集商业化处理后返回列表；文档中图片按短边不超过320、JPG80%压缩，scene_code和媒体pid必填，移动标识字段为可选。仍需确认厂商场景权限及我们的网页用途是否准入，不能视为淘宝全量搜索。
- [拍立淘插件转链，apiId=53998](https://developer.alibaba.com/docs/api.htm?apiId=53998)只返回插件URL/deeplink，其请求参数不含商品图片。不能用它证明可将OZON图片一键预置并拿回结果。
- “不需要授权”指文档中的用户Session授权，不代表无需开发者注册/应用权限或所有个人账号均可使用。

### 拼多多

- 官方[开放平台](https://open.yangkeduo.com/application/home)存在，不等于对我们开放任意图片搜索全部平台商品。本次未找到足够的官方公开文档，能证明存在适用于此网页场景的通用图搜商品列表接口；这是证据限制，不断言平台内部没有图搜能力。
- [AiPrice开发者论坛](https://www.aiprice.com/vi/bbsforum)2026-10-08 10:39:32对用户“以图搜图没有拼多多的选项”回复：“去掉拼多多了，因为官方风控太严，搜不了。”官网仍可见旧支持宣传，具体最新功能回复应优先参考；这一事实仅说明该供应商当时的状态，不能外推所有供应商永久不可用。
- 目前不能承诺拼多多自动稳定图搜比价；保留人工找货、保存采购链接的替代方案。关键词搜索加图片相似度筛选不等同于真正的全站以图搜图。

## 第三方候选（未实测，不是背书）

- [HioBuy图搜文档](https://hiobuy.com/zh/api-docs/product-image-search)明确有 `POST /v1/products/search-by-image`，channel支持1688/taobao，接受图片URL、Base64或上传后image_id，可选裁剪区域。没有据此证明支持拼多多。须确认能否独立订购只读检索、套餐、超时与失败计费、数据用途及覆盖范围。
- [TMAPI 1688多语言图搜](https://tmapi.top/zh-cn/docs/ali/cross-border/search-items-by-image-url)说明部分图搜只识别阿里图片，非阿里图须先转换，不能直接把OZON图片URL当成通用参数。其[入门说明](https://tmapi.top/zh-cn/docs/start)提供注册和少量试用额度说明，实际条件以开通时为准。
- [AiPrice API合作说明](https://www.aliprice.com/independent/detail?article_id=2069&category_id=604)列出1688上传、图搜及详情API，需要商务联系；不能把插件支持的平台范围直接当作对外API支持范围。
- 万邦旧淘宝图搜文档访问时重定向到[淘宝海外tglobal接入说明](https://open.onebound.cn/help/api/tglobal.readme.html)，其中列upload_img/item_search_img；仅是候选技术线索，旧营销文章与接口名称不能充当当前可用性保证。
- 阿里云/腾讯云开发者社区的用户文章不等同平台官方接口文档。凡仅在博文出现的接口名、免费额度和“99.9%稳定”说法，未列为已证实事实。

## 适合现有项目的方案（建议，未实施）

1. 每个商品增加“找货比价”入口；多商品订单按商品独立查询，点击时再检索，不在列表加载时批量收费调用。
2. 阿里云Flask调用已获权限的官方接口或经过试用的供应商，浏览器显示图片、平台、店名、候选规格、参考价格及查询时间；各平台独立展示成功、失败或无结果。
3. 图片外链被拒绝时，由受限的现有商品图片来源读取并压缩/上传，按供应商实际要求处理；不依赖任意URL直传。仅发送商品图片及必要检索字段，不发送订单、客户或OZON密钥。
4. 先按原图内容哈希、平台和查询选项缓存结果，手动刷新；同商品跨店重复出现复用结果。每日调用预算和限频适用于现有免登录页面，不改变已确认的访问偏好。
5. 规格、件数、材质、起订量、运费、优惠条件须分开，参考价不直接覆盖真实采购成本。可由用户确认并保存货源链接/规格，再复用到以后相同商品。
6. 按供应商拆开适配，预留独立凭证/配额的扩展点。现有OZON Key只用于现有OZON数据，不能代替其他平台或供应商的Key。
7. 服务器只做轻量HTTP请求和缓存，不部署本地视觉模型或常驻浏览器集群。现有2GB机器不宜为此增加重型视觉检索服务。

## 不建议的做法

- 服务器长期模拟登录三平台、抓网页作为主要数据来源：页面、登录验证和风控变化都由我们维护，稳定性与低成本目标冲突。
- 直接拼未经承诺的搜图URL、隐藏抓取第三方插件结果，或用插件内部接口作为生产依赖。
- 自建向量库当成全网商品库：图像搜索引擎本身不包含三平台实时商品和价格。需另外解决商品数据来源，当前规模不划算。
- 宣称“100%同款、全网最低价”。图相同可能是不同尺寸/配件，图搜价格可能是最低规格、阶梯价或有条件优惠价。

## 开发前最小验证及费用

建议先选10至20张有已知采购链接及实际规格的OZON商品图，对比官方1688和候选淘宝来源：前10个结果有无真实同款、链接能否打开、规格与价格能否核对、超时/空结果是否收费、重复请求缓存情况。只做小样本验证，不做全店扫描。

1688本次未取得可验证的具体图搜报价；淘宝上述官方文档虽标免费，不能据此承诺当前账号可开通；第三方需确认最小充值、月套餐及失败计费。费用模型是“未命中缓存的图搜次数×单次价格 + 上传/商品详情请求费用 + 套餐最低消费”，不能把一次三平台查询等同一次计费。

官方采购助手可用于先人工观察1688/淘宝效果，成本最低的验证路径之一；但它不是我们网页内的聚合接口，未确认网页可程序化唤起及读回结果。拼多多如必须同样全自动且稳定，当前不应承诺交付。
